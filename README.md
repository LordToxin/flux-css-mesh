## 🇬🇧 Overview

**FluxMesh Studio** is a client-side visual synthesizer designed for modern frontend engineers, UI/UX designers, and product creators. Traditional CSS gradients are flat and predictable; FluxMesh renders multi-point radial dispersion meshes coupled with real-time glassmorphism optics.

### ✨ Key Capabilities
* **Interactive Mesh Canvas**: Drag color pins in real-time across the viewport to re-project radial energy vectors.
* **Curated Palette Presets**: Includes *Toxic Emerald*, *Cyberpunk Noir*, *Tokyo Night*, *Solar Flare*, *Nordic Aurora*, and *Deep Cosmos*.
* **Real-time Glassmorphism Optics**: Tune backdrop blur, alpha transparency, border specular highlights, and color saturation on the fly.
* **Instant Export Engine**:
  * **Pure CSS**: Native multi-layer radial gradients with blend-mode fallbacks.
  * **Tailwind CSS**: Arbitrary-value production classes ready to paste into your Next.js/React templates.
  * **Vector SVG**: Scalable vector markup for Figma or UI assets.
  * **4K UHD Render**: Instant 3840×2160 PNG wallpaper generation rendered via an offscreen HTML5 canvas buffer.
* **Zero Dependencies**: Pure HTML5, CSS3, and modern Vanilla ES6+. No heavy build steps or npm baggage required.

## 🇷🇺 Описание проекта

**FluxMesh Studio** — высокопроизводительный визуальный генератор органических CSS меш-градиентов и эффектов стекла (Glassmorphism) с мгновенным экспортом кода.

### Основные фичи:
* **Интерактивный Drag-and-Drop**: прямое перетаскивание узлов цвета по холсту с мгновенным перерасчетом радиальных градиентов.
* **Библиотека стилей**: киберпанк, неоновый изумруд, ночной Токио, глубокий космос и северное сияние.
* **Настройка матового стекла**: управление размытием (`backdrop-filter: blur`), сатурацией, прозрачностью подложки и бликом контура.
* **Экспорт в 1 клик**:
  * Чистый CSS3 код.
  * Готовые классы Tailwind CSS.
  * Векторный SVG для верстки и Figma.
  * Скачивание фоновых обоев в разрешении 4K Ultra-HD (3840x2160).

## 🚀 Quick Start / Быстрый запуск

No build tools needed. Simply clone and open:

```bash
git clone https://github.com/LordToxin/flux-css-mesh.git
cd flux-css-mesh

# Open directly in your browser:
start index.html
```

Or run with any local web server:
```bash
npx serve .
# or
python -m http.server 3000
```
